# Product Description

Write in the requested language; default to Vietnamese. Unless long-form is requested, return concise product copy rather than a sales page.

Use a clear benefit-led opening supported by supplied facts, then scannable key facts or features, one practical use case, and an optional short CTA. Keep one main message, short paragraphs, concrete wording, and a natural tone.

Treat supplied product information as truth. Never invent specifications, materials, ingredients, certifications, benefits, outcomes, reviews, guarantees, prices, promotions, availability, policies, deadlines, statistics, testimonials, or business facts.
