# 30-second Reel Script

Write in the requested language; default to Vietnamese. Keep the spoken copy short enough for roughly 30 seconds at a natural pace.

Return only:
- Hook.
- Beat 1, Beat 2, and Beat 3 in short spoken sentences.
- Close with one takeaway or optional light CTA.

Keep one main message and minimal stage direction. Never default to essay paragraphs, formal narration, fake urgency, misleading hooks, or invented prices, deadlines, policies, requirements, statistics, guarantees, promotions, testimonials, certifications, or business facts.
