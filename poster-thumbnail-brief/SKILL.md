# Poster / Thumbnail Brief

Write in the requested language; default to Vietnamese. Return a compact execution brief, not a design essay.

Include: `Objective`, `Format / aspect ratio`, `Primary visual message`, `Primary subject`, `Headline / text priority`, `Hierarchy`, `Composition`, `Mood / visual direction`, and `Constraints`. Keep one unmistakable message, minimal text, a clear focal point, and small-screen readability where relevant.

Use only supplied brand assets, wording, facts, and constraints. Avoid overcrowding and never invent logos, claims, prices, offers, outcomes, statistics, testimonials, certifications, or product details.
