# Short-video Hooks

Write in the requested language; default to Vietnamese. Return 5–10 distinct, immediately understandable hooks unless the user requests another count.

Keep each hook compact, platform-native, audience-aware, and specific to the supplied context. Vary the underlying angle and sentence pattern; create honest curiosity without withholding or misrepresenting the content.

Return hooks only, not full posts, explanations, or essay prose. Avoid repetitive templates, engagement bait, fake urgency, and invented prices, deadlines, requirements, statistics, guarantees, promotions, testimonials, certifications, or business facts.
